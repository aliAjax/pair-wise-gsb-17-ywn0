# hxwl-03 监测井成井验收台

在已有钻孔上登记目标含水层、筛管、滤料与止水段，完成成井验收：结构校验、两次洗井达标并经班组长确认后冻结记录，修正另建原因版本。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 功能

- 钻孔册选孔登记：目标含水层、筛管段、滤料段、止水段深度
- 结构五条校验（实时）：
  - 各段深度合法（顶深<底深，不超出孔深）
  - 筛管落在目标含水层内
  - 滤料段包住筛管
  - 滤料段不越过含水层
  - 止水段与筛管重叠即指出冲突
- 成井结构纵断面示意图，止水与筛管重叠区标红
- 洗井记录两次含砂量（≤10 mg/L）与浊度（≤10 NTU）
- 结构合规 + 两次洗井达标 + 班组长确认后方可冻结
- 冻结记录不可改，修正需填写原因重开新版本（版本历史留痕）
- 验收台账按孔号自然排序（ZK-09 在 ZK-18 前），未验收井与重开井不插队
