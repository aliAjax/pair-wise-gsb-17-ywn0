# hxwl-03 岩土钻孔编录 · 成井验收台

在已有钻孔上完成监测井成井登记、结构校验、洗井记录与验收冻结的现场面板。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 功能

- **已有钻孔选择**：钻孔列表按孔号自然排序，标注未登记 / 未验收 / 已冻结状态
- **成井结构登记**：目标含水层（顶/底板）、筛管段、滤料段、止水段深度录入，附成井结构示意图
- **结构冲突随录随查**：
  - 筛管须落在目标含水层内
  - 滤料须包住筛管且不越出含水层边界
  - 止水段触碰到筛管即报冲突
- **洗井记录**：两次含砂量（体积比 1:N，N ≥ 20000）与浊度（≤ 10 NTU），逐次判定达标
- **验收冻结**：结构校验全通过 + 两次洗井达标 + 班组长确认后方可冻结；冻结后只读
- **修正版本**：冻结记录修正须填写原因并另建新版本，历史版本留痕
- **成井台账**：未验收井与冻结重开的井始终按孔号排列，数据经 localStorage 持久化
